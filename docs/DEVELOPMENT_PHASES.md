# Evolución técnica del proyecto

Esta síntesis explica la construcción de la plataforma desde la perspectiva de ingeniería. No reproduce los informes internos, sesiones de desarrollo ni registros de comandos.

| Etapa | Resultado técnico |
|---|---|
| 0 | Estructura de CMake, dependencias, contratos iniciales y pruebas base. |
| 1 | Escenas, transformaciones y cámaras. |
| 2 | Importación de geometría y recursos GLB. |
| 3 | Materiales, iluminación y técnicas de entorno. |
| 4 | Selección, manipulación y animaciones con distintos mecanismos. |
| 5 | Plaza central, navegación entre zonas y SDK modular v1.0. |
| 6A | Instalación EcoEnergy. |
| 6B | Instalación AquaBio. |
| 6C | Instalación EcoCycle. |
| 6D | Cinco modelos compartidos entre las zonas. |
| 6E | Ajustes de experiencia del visitante, HUD, pausa/reinicio y regresiones. |

El estado integrado de la base contiene **110 modelos únicos, 252 instancias, 20 interacciones educativas y 24 animaciones**. Se han usado pruebas automatizadas y recorridos gráficos en Linux. Los resultados exactos de esta edición pública deben volver a verificarse de manera independiente.

El desarrollo colaborativo continúa; el instalador y los documentos de entrega final no forman parte de esta base inicial.
